# Security policy

## Reporting a vulnerability

Do not publish credentials, private model outputs, provider error bodies, or a
working exploit in a public issue.

Use this repository's **Security** tab to submit a private vulnerability report
when that feature is available. If it is unavailable, open a minimal issue that
asks the maintainers to establish a private channel; include no sensitive
details in that issue.

Please include the affected commit or release, the trust boundary involved,
reproduction prerequisites, and whether the report concerns local verification
or an external platform. Maintainers will acknowledge the report before asking
for additional sensitive material.

## Supported versions

No standalone release is supported yet. Commit `f37fa45` is a historical
generated preview, not a security-supported benchmark distribution. This file
will list supported release lines after the authority cutover gate passes.
