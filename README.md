# aleph-benchmark

Public benchmark repository for Aleph.

This repository currently publishes the benchmark materials that were present locally but had not been pushed into a dedicated public repo yet.

## What is here

- `platform/m0-mock/`: the current AlephBench Frozen Ladder M0 platform package.
- `references/kaggle-bench/`: local Kaggle Benchmarks syntax notes and a minimal example task.

## Evidence boundary

The `platform/m0-mock/evidence/` directory contains deterministic mock pipeline artifacts. They document the benchmark package and scoring flow, but they are not real cross-model leaderboard results.

Treat this repository as the public home for benchmark assets, schemas, mock evidence, and platform packaging material. Do not cite the mock evidence as real model ranking.
